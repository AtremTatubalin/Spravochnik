# Матрица готовности данных

| Набор | В архиве | Что требуется для production |
|---|---|---|
| Метаданные стандартов | 15 проверенных записей | расширить реестр, добавить все изменения |
| Материалы | 20 структурных карточек | свойства по состояниям и диапазонам |
| Подшипники | 4 проверенных примера | массовый импорт каталогов производителей |
| Допуски и посадки | схема и CSV | официальный импорт таблиц 25346/25347 |
| Прямобочные шлицы | мастер и CSV | таблицы ГОСТ 1139-80 с изменениями |

Статус `структурная карточка` означает, что запись пригодна для связывания и поиска, но не содержит непроверенных числовых свойств.
