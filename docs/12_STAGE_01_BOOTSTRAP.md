# Этап 01: bootstrap репозитория

Реализованы модули из технической архитектуры, convention plugins, каталог версий, Dark CAD тема, навигационная оболочка, CI и ADR. Бизнес-функции и нормативные данные не добавлялись.

## Проверка версий
Версии сверены 2026-08-04 с официальными Maven metadata Google и Maven Central. Для совместимого toolchain зафиксированы AGP 8.11.1, Kotlin 2.2.20 и Gradle 8.14.3. AndroidX зафиксирован на последних стабильных релизах, совместимых с compile SDK 36 и AGP 8.11; релизы, уже требующие SDK 37/AGP 9.1, сознательно отложены. Полный список находится в `gradle/libs.versions.toml`.

## Нерешённые нормативные данные
Все позиции `data/MISSING_DATA_REGISTER.csv` остаются нерешёнными. Этот этап не импортирует таблицы и не меняет статусы записей.
