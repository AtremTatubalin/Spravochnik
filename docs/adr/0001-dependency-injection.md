# ADR 0001: Ручное внедрение зависимостей

- Статус: принято
- Дата: 2026-08-04

## Решение
На этапе bootstrap применяется ручной DI через корневой `AppContainer`. Контейнер появится вместе с первым репозиторием. Это сохраняет граф явным, не добавляет генерацию кода и подходит offline-first приложению. Если граф существенно вырастет, переход на Hilt оформляется новым ADR.
