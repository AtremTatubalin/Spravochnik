## Ключевой пользовательский сценарий

1. Создать проект.
2. Добавить деталь или узел.
3. Выбрать мастер измерений.
4. Отметить реально доступные размеры.
5. Получить несколько кандидатов с оценкой достоверности.
6. Выполнить проверочный расчёт.
7. Сохранить исходные данные, формулы, источники и результат.
8. Сформировать PDF/JSON/CSV отчёт.

## Обязательные статусы результата

- `confirmed` — данные однозначны и прошли проверки;
- `calculated` — число вычислено из подтверждённых входов;
- `candidate` — один из нескольких возможных вариантов;
- `insufficient_data` — данных недостаточно;
- `requires_standard_table` — отсутствует импорт нормативной таблицы;
- `requires_engineer_review` — требуется инженерная проверка;
- `invalid_input` — исходные данные противоречат друг другу.
