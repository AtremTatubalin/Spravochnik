# Архитектура мастеров реверс-инжиниринга

## Общая модель

Каждый мастер хранится как данные: шаги, доступные измерения, правила кандидатов, функция оценки и запрос следующего наиболее информативного измерения.

## Оценка кандидата

```text
score = Σ(weight_i × match_i) − contradiction_penalty − missing_critical_penalty
```

Где `match_i` находится от 0 до 1 и учитывает погрешность измерения и износ.

## Подшипник

Обязательные размеры: `d`, `D`, `B`. Дополнительные: тип тел качения, число рядов, уплотнения, канавка, фланец, маркировка. Результат — точные совпадения и ближайшие кандидаты с отклонениями.

## Метрическая резьба

Измерения: наружный/внутренний диаметр, шаг, направление, число заходов, цилиндрическая/коническая. Следующее рекомендуемое измерение выбирается по тому, какое сильнее разделяет оставшиеся кандидаты.

## Прямобочный шлиц

Измерения: `z`, `D`, `d`, `b`, длина, тип центрирования. Кандидаты формируются только из импортированной таблицы ГОСТ 1139-80. Без таблицы мастер показывает лишь геометрический протокол измерения.

## Эвольвентный шлиц

Измерения: `z`, наружный и внутренний диаметры, размер по роликам или общая нормаль, диаметр ролика, угол профиля. Кандидаты модуля проверяются по импортированной таблице ГОСТ 6033-80. Наружный диаметр изношенной детали имеет меньший вес, чем размер по роликам.

## Зубчатое колесо

Для стандартной прямозубой передачи без смещения предварительная оценка `m ≈ d_a/(z+2)`. Это не доказательство модуля. Кандидат подтверждается общей нормалью, размером по роликам, межосевым расстоянием пары или сопряжённой деталью. Для косозубого колеса дополнительно нужны угол и направление зуба.

## Правило интерфейса

Мастер обязан разделять:

- измеренное;
- вычисленное;
- принятое;
- найденное в таблице;
- предположительное.
