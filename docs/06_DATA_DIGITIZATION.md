# Оцифровка и контроль справочных данных

## Запрещённый подход

Нельзя загрузить PDF в OCR, автоматически выгрузить таблицы и считать базу готовой. Ошибка одной цифры в допуске или нагрузочной характеристике делает справочник опасным.

## Конвейер

```text
Официальный источник
→ регистрация источника и лицензии
→ извлечение текста/таблицы
→ черновой CSV
→ нормализация единиц и обозначений
→ двойная ручная сверка
→ машинные проверки диапазонов
→ контрольная выборка минимум 10 %
→ JSON/SQLite seed
→ тестовый импорт
→ визуальная сверка в приложении
→ статус verified
```

## Структура рабочих файлов

```text
data/imports/raw/
data/imports/extracted/
data/imports/review_1/
data/imports/review_2/
data/imports/approved/
```

## Обязательные поля происхождения

- source_id;
- standard/catalog designation;
- edition/revision;
- page/table/row;
- extraction method;
- reviewer_1;
- reviewer_2;
- verified_at;
- checksum исходного файла;
- license_scope.

## Правила OCR

- OCR использовать только как средство чернового ввода;
- десятичные запятые и точки нормализовать отдельно;
- символы `0/O`, `1/l/I`, `Х/X`, `Н/H`, `С/C` проверять программно;
- диапазоны не разрывать на два независимых значения;
- единицы не выводить из контекста автоматически без флага проверки;
- таблицы допусков проверять по монотонности и граничным интервалам.

## Контрольные правила

- `min <= max`;
- размеры положительны;
- внутренний диаметр меньше наружного;
- масса и площадь сечения взаимно проверяются через плотность;
- у подшипника `d < D`, `B > 0`, нагрузки положительны;
- дата введения не раньше даты принятия;
- заменяющий стандарт не активируется раньше `effective_from`;
- свойства материала обязательно привязаны к состоянию.
