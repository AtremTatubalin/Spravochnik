# План разработки

## Этап 0 — репозиторий

- Gradle convention plugins;
- CI: lint, unit tests, database validation;
- ADR для DI и многомодульности;
- базовая тема Dark CAD.

## Этап 1 — вертикальный срез

- Room;
- импорт seed manifest;
- главная и поиск;
- материалы (структурные карточки);
- подшипники;
- проекты;
- калькулятор ресурса подшипника;
- мастер подбора подшипника по размерам.

## Этап 2 — механические соединения

- резьбы;
- крепёж;
- шпонки;
- шлицы;
- базовые расчёты;
- мастер определения шлица.

## Этап 3 — передачи и сортамент

- зубчатые передачи;
- цепи/ремни;
- сортамент;
- масса и геометрические характеристики;
- мастер зубчатого колеса.

## Этап 4 — отчёты и обновления

- PDF/CSV/JSON;
- подписанные пакеты обновлений;
- резервное копирование проектов;
- журнал версии данных.

## Definition of Done для калькулятора

- формула и границы применимости описаны;
- валидация входов;
- минимум 5 unit-тестов, включая граничные;
- эталонный пример проверен независимо;
- результат содержит формулу, единицы, допущения, предупреждения;
- есть сохранение в проект;
- есть доступность и локализация.
