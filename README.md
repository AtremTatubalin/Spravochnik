# Справочник конструктора — пакет проектирования v0.1

Выбранный интерфейс: **тёмный CAD стиль**.

Дата фиксации нормативного реестра: **2026-08-04**.

Этот архив предназначен для передачи Codex или разработчику. В нём находятся:

- полная продуктовая и техническая архитектура;
- схема SQLite/Room;
- форматы справочных данных;
- стартовая база метаданных стандартов с официальными источниками;
- стартовые записи материалов и подшипников;
- каталог формул и границы применимости калькуляторов;
- сценарии реверс-инжиниринга;
- дизайн-система Dark CAD;
- инструкции по оцифровке нормативных таблиц;
- основной и поэтапные промпты для Codex;
- шаблоны чистого Kotlin-ядра расчётов;
- скрипты проверки JSON и SQLite.

## Важное ограничение

Архив **не содержит полного текста стандартов и не воспроизводит защищённые нормативные таблицы**. Он содержит архитектуру, метаданные, проверенные открытые формулы и механизм легального импорта таблиц из официально приобретённых документов. Значения, зависящие от состояния поставки, термообработки, диаметра, температуры, класса точности или исполнения, нельзя хранить одним числом в карточке материала/изделия.

## С чего начать

1. Прочитать `docs/00_SCOPE_AND_STATUS.md`.
2. Передать Codex файл `prompts/00_MASTER_CODEX_PROMPT.md` вместе со всем архивом.
3. Запускать разработку по заданиям `prompts/01...08` строго последовательно.
4. Выполнить `python scripts/validate_package.py`.
5. Для нормативных таблиц использовать процесс из `docs/06_DATA_DIGITIZATION.md`.

## Сборка Android-приложения

Требуются JDK 17 и Android SDK 36. Укажите путь к SDK через `ANDROID_HOME` или
`local.properties`, затем используйте Gradle Wrapper. При первом запуске wrapper
загружает официальный bootstrap JAR Gradle 8.14.3 в пользовательский каталог
`GRADLE_USER_HOME` и проверяет его SHA-256; бинарный JAR намеренно не хранится
в репозитории:

```bash
./gradlew assembleDebug
./gradlew test
./gradlew lint
```

APK отладочной сборки создаётся в `app/build/outputs/apk/debug/`. Проверка
исходного пакета данных выполняется отдельно командой
`python scripts/validate_package.py`.

Навигационная оболочка содержит только экраны-заглушки: бизнес-функции будут
добавляться последующими этапами `prompts/02...08`.

### Сборка APK на GitHub

Workflow `Android CI` запускается автоматически для push и pull request. Его
также можно запустить вручную на странице **Actions → Android CI → Run
workflow**. После успешной сборки APK доступен внизу страницы запуска в разделе
**Artifacts** под именем `spravochnik-debug-<commit SHA>`. Артефакт хранится 14
дней и не добавляется в Git-репозиторий.
