# Как использовать пакет

## Передача Codex

Передайте Codex весь архив или распакованную папку. Первое сообщение должно содержать текст из `prompts/00_MASTER_CODEX_PROMPT.md`. Codex должен сначала прочитать `AGENTS.md` и документы, затем выполнять этапы 01–08.

## Рекомендуемый режим работы

- один этап — одна ветка Git;
- каждый этап заканчивается тестами и draft PR;
- не разрешать Codex добавлять нормативные числа без `source_id`;
- любые таблицы ГОСТ импортировать отдельным коммитом;
- перед объединением нормативных данных проводить ручную выборочную сверку.

## Добавление официальной таблицы

1. Зарегистрировать источник в `sources`.
2. Заполнить подходящий CSV из `data/import_templates`.
3. Указать страницу/таблицу/строку.
4. Провести две независимые сверки.
5. Прогнать валидатор.
6. Сгенерировать seed-пакет с новой версией.
7. Импортировать в тестовую БД.
8. Проверить карточки и контрольные расчёты.

## Контроль

```bash
python scripts/validate_package.py
python scripts/check_reference_examples.py
```

## Следующее практическое действие

Сначала реализовать вертикальный срез: база → подшипники → калькулятор L10 → проект → отчёт. Только после этого расширять таблицы материалов, посадок и шлицев.
